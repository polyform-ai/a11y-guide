# Helpful prompts

These prompts are starting points for adopting `@polyform-ai/a11y-guide` in real applications. Copy one into your coding agent, replace any repository-specific placeholders, and review every proposed accessibility or workflow change before merging it.

- [Make the Polyform product agent-ready](polyform-product-agent-readiness.md) — a React 19, React Router 8, Vite, and TypeScript integration and audit task.
- [Audit a public site without unbounded crawling](audit-a-public-site.md) — a read-only, representative-page audit for ordinary sites and large publications.

Contributions are welcome. Add focused prompts for other frameworks, page patterns, accessibility-tree reviews, and browser-agent tests. Include the stack, safety boundaries, expected evidence, and validation commands instead of asking an agent to make a site generically “AI-ready.”
